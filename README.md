## This is a Guided End to End ML Project

This Project deals with creating a project structure, pipelines and deploying it in a professional manner. The dataset taken is about an ecommerce buisness (Souq.com) that deals with a variety of products and categories and its sales trends.
Further into the project we do ML analysis and provide Predictive analysis for the ecommerce buisness to help increase its sales using ML models and automating it.
